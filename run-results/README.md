# Run Results

This folder contains sanitized public summaries of representative REC runs.

These are not raw model transcripts. They are curated result bundles intended to show the shape of REC's research-state artifacts without publishing private paths, prompts, cached papers, or unreviewed bulk logs.

## Included Runs

- `gompf/`: cluster benchmark over the 22-target Gompf problem list.
- `rp2/`: Lagrangian `RP2` packing-cone case study.

## Interpretation Rule

For research-level mathematics, a run result should not be read as a solved theorem unless it has independent mathematical verification or formal proof checking.

The primary outputs here are research-state artifacts:

- locked targets
- route matrices
- failure ledgers
- verifier summaries
- reusable statements
- next-target recommendations
- attack certificates

These artifacts are meant to help a mathematician or future agent continue the investigation.
