# ICML 2026 AI4Math Workshop Paper

This directory contains the camera-ready version of the AI4Math Workshop paper:

**Recurrence: An Evolving Research-State Copilot for Mathematics**

Files:

- `recurrence-final.pdf`: camera-ready PDF.
- `recurrence-final.tex`: LaTeX source.
- `recurrence.bib`: bibliography.
- `icml2026.sty`, `icml2026.bst`, and helper style files: vendored ICML 2026 style files used for the camera-ready build.

Build from this directory with:

```bash
tectonic recurrence-final.tex
```
