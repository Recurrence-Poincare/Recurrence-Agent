# Toy Output

This directory shows the expected artifact shape for a small REC run. It is a sanitized example, not model output from a serious mathematical run.

The point is to make the artifact contract concrete:

- `locked-statement.md`
- `method-matrix.jsonl`
- `counterexample-attempts.jsonl`
- `statement-drift-report.md`
- `verification-report.md`
- `attack-certificate.md`
